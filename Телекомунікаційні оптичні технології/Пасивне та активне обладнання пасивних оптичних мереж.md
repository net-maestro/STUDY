## ВСТУП

**Актуальність теми.** Впровадження пасивних оптичних мереж (PON) у багатоквартирних житлових комплексах є ключовим фактором цифрової трансформації України. Технології FTTB (Fiber To The Building) та FTTH (Fiber To The Home) забезпечують високошвидкісний доступ до Інтернету, IP-телефонії та інтерактивного телебачення.

Ефективність PON-мереж безпосередньо залежить від правильного вибору та інтеграції двох основних груп обладнання:

- **Пасивного** — оптичні сплітери, кабелі, конектори, муфти (не потребують живлення);
- **Активного** — OLT, ONT/ONU (вимагають електроживлення, обробляють сигнали).

**Мета роботи** — провести системний аналіз пасивного та активного обладнання PON-мереж з акцентом на рішення для багатоквартирних будинків на базі обладнання провідних виробників Huawei та ZTE.

**Завдання:**
- Класифікувати та охарактеризувати пасивні компоненти PON;
- Дослідити архітектуру та функціонал активного обладнання;
- Проаналізувати специфіку обладнання SFU, HGU, MDU;
- Розглянути практичні аспекти розгортання мережі в ЖК.

## РОЗДІЛ 1. ПАСИВНЕ ОБЛАДНАННЯ PON-МЕРЕЖ

### 1.1. Оптичні сплітери

**Оптичний сплітер** — ключовий пасивний елемент PON, що розділяє один вхідний оптичний сигнал на N вихідних з мінімальними втратами.

#### **Технологія PLC (Planar Lightwave Circuit)**

```
Вхідне волокно (1)
        ↓
┌───────────────────────┐
│  Кремнієва підкладка  │
│  Planar Waveguide     │
│  Array (Y-подібні     │
│  розгалуження)        │
└───────────────────────┘
        ↓
  N виходів (1:N)
```

#### **Характеристики сплітерів для багатоквартирних будинків:**

| Коефіцієнт | Втрати, дБ | Рівномірність, дБ | Застосування |
|------------|------------|-------------------|--------------|
| **1:4** | 7.2 ± 0.5 | ≤0.3 | Каскадна схема (1-й рівень) |
| **1:8** | 10.5 ± 0.8 | ≤0.4 | Каскадна схема (2-й рівень) |
| **1:16** | 13.8 ± 1.0 | ≤0.5 | FTTB (під'їзд) |
| **1:32** | 17.0 ± 1.2 | ≤0.6 | **Оптимально для ЖК** |
| **1:64** | 21.0 ± 1.5 | ≤0.8 | Висока щільність |

**Додаткові параметри:**
- Робочі довжини хвиль: **1260–1650 нм** (повний спектр)
- Робоча температура: **-40°C ... +85°C**
- Термін служби: **≥25 років**
- Поляризаційна залежність (PDL): **≤0.2 дБ**

#### **Типи конструктивного виконання:**

```
1. Box-type (корпусний, IP68)
   └─ Для зовнішньої установки (вулиця, підвал)
      └─ Кріплення: стіна, опора, шафа

2. Rack-mount (стійковий, 19")
   └─ Для установки в ODF/кроси
      └─ Формат: 1U–2U, 8–144 порти

3. Module-type (модульний)
   └─ Для інтеграції в кроси
      └─ Компактний, швидка заміна
```

### 1.3. Конектори та адаптери

#### **Типи конекторів у PON:**

| Тип | Колір | Полірування | ORL | Застосування |
|-----|-------|-------------|-----|--------------|
| **SC/APC** | 🟢 Зелений | Кут 8° | ≥65 дБ | **Стандарт для PON** |
| **LC/UPC** | 🔵 Синій | Площина | ≥55 дБ | SFP-модулі, ODF |
| **FC/APC** | 🟢 Зелений | Кут 8° | ≥65 дБ | Вимірювальне обладнання |

#### **Чому SC/APC — стандарт для PON?**

```
APC (Angled Physical Contact) — кут полірування 8°

Переваги:
✅ Відбите світло не повертається у волокно
✅ ORL ≥65 дБ (проти 55 дБ у UPC)
✅ Критично для чутливих приймачів PON

      ┌─────────┐
Світло →  8° кут  → Відбиття йде ВБИК від волокна
      └─────────
```

**Технічні вимоги:**
- Загасання: **≤0.3 дБ**
- Повторюваність: **≥500 підключень**
- Робоча температура: **-40°C ... +85°C**

## РОЗДІЛ 2. АКТИВНЕ ОБЛАДНАННЯ PON-МЕРЕЖ

### 2.1. OLT (Optical Line Termination)

**OLT** — центральне активне обладнання на стороні провайдера, що керує всіма ONT у мережі.

#### **Функції OLT:**

```
┌─────────────────────────────────────────┐
│              OLT (рівні)                 │
├─────────────────────────────────────────┤
│  Сервісний рівень  │ QoS, VLAN, шифру-  │
│                    │ вання AES-128, OAM │
├─────────────────────────────────────────┤
│  Транспортний      │ GEM/GTC інкапсуля- │
│  рівень            │ ція, DBA (динаміч- │
│                    │ на смуга)          │
├─────────────────────────────────────────┤
│  Фізичний рівень   │ Оптичні трансивери │
│                    │ (SFP/SFP+), коду-  │
│                    │ вання              │
└─────────────────────────────────────────┘
```

### 2.2. Класифікація ONT: SFU, HGU, MDU

#### **1. SFU (Single Family Unit)**

**Призначення:** Окрема квартира/приватний будинок

```yaml
Моделі:
  • Huawei HG8245H / HG8245Q
  • ZTE F660 / F670

Інтерфейси:
  PON: 1× GPON (SC/APC)
  Ethernet: 4× GE (10/100/1000BASE-T)
  Телефонія: 2× POTS (FXS)
  Wi-Fi: 802.11 b/g/n/ac (2.4/5 ГГц)
  USB: 1× USB 2.0 (опціонально)
  RF: 1× F-type (для TV, опціонально)

Функціонал:
  • Bridge-режим (прозора передача)
  • Базовий маршрутизатор
  • VoIP (SIP, H.248)
  • IPTV (IGMP snooping)
  • Управління: OMCI, TR-069

Ціна: $25–45
```

**Застосування:** Квартира, де провайдер надає повний сервіс (Інтернет + ТБ + телефонія).

---

#### **2. HGU (Home Gateway Unit)**

**Призначення:** Розширений функціонал для розумного дому

```yaml
Моделі:
  • Huawei HG8245W5 / HG8145V5
  • ZTE F673A / F680

Відмінності від SFU:
  ✅ Розширений Wi-Fi 6 (802.11ax)
  ✅ Mesh-мережа (кілька точок доступу)
  ✅ USB 3.0 (зовнішній накопичувач, принтер)
  ✅ Розширений QoS
  ✅ Батьківський контроль
  ✅ Гостьова мережа Wi-Fi
  ✅ MoCA (через коаксіал, опціонально)

Функціонал:
  • Повноцінний роутер (NAT, DHCP, Firewall)
  • VPN-сервер/клієнт
  • Dynamic DNS
  • Port forwarding
  • DLNA/медіасервер

Ціна: $45–80
```

**Застосування:** Квартири з високими вимогами до Wi-Fi, розумний дім, геймінг.

---

#### **3. MDU (Multi-Dwelling Unit)**

**Призначення:** Багатоквартирний будинок (під'їзд/підвал)

```yaml
Моделі:
  • Huawei MA5671A / MA5675
  • ZTE F820 / C600

Інтерфейси:
  PON Uplink: 1× GPON (SC/APC)
  Ethernet Downlink: 8–24× GE
  SFP слоти: 2–4× (для uplink або додаткових портів)
  POTS: 16–48× (для телефонії на весь будинок)

Функціонал:
  • Агрегація трафіку від багатьох квартир
  • VLAN per port
  • QoS на рівні порту
  • STP/RSTP (захист від петель)
  • Link aggregation (LACP)
  • Дистанційне управління (SNMP)

Живлення:
  • AC 220V або DC -48V
  • Резервне живлення (опціонально)
  • PoE/PoE+ (для IP-камер, точок доступу)

Кріплення:
  • 19" стійка або настінне
  • Розмір: 2U–4U

Ціна: $150–400
```

**Застосування:** FTTB-архітектура, коли волокно доходить до підвалу/під'їзду, а далі мідь (UTP) до квартир.

## ПРАКТИЧНИЙ ПРИКЛАД ПОБУДОВИ МЕРЕЖІ ДЛЯ ЖК

### **Завдання:**
Побудувати PON-мережу для ЖК "Сонячний" (3 будинки × 10 поверхів × 40 квартир = **120 квартир**).

### **Архітектура: FTTB + частково FTTH**

```
                    ┌─────────────┐
                    │ OLT (CO)    │
                    │ MA5680T     │
                    │ 2×GPON плат │
                    └──────┬──────┘
                           │
                    ┌──────┴──────┐
                    │ Магістраль  │
                    │ 24 волокна  │
                    │   6.2 км    │
                    └────────────
                           │
              ┌────────────┴────────────┐
              │   Головна шафа (підвал) │
              │  Splitter 1:4 × 3 шт    │
              └─────┬─────┬─────┬───────┘
                    │     │     │
              Будинок 1 Будинок 2 Будинок 3
                    │         │         │
              Splitter  Splitter  Splitter
               1:32      1:32      1:32
                    │         │         │
              [ONT×40]  [ONT×40]  [ONT×40]
```

### **Розрахунок оптичного бюджету:**

```
Відстань OLT → ЖК: 6.2 км
Загасання волокна: 6.2 × 0.25 = 1.55 дБ

Сплітер 1:4: 7.2 дБ
Сплітер 1:32: 17.0 дБ
Конектори (4 шт): 4 × 0.3 = 1.2 дБ
Зварні з'єднання (6 шт): 6 × 0.08 = 0.48 дБ
Запас на деградацію: 3.0 дБ

РАЗОМ: 1.55 + 7.2 + 17.0 + 1.2 + 0.48 + 3.0 = 30.43 дБ

Вибір: GPON Class C+ (бюджет до 32 дБ) ✅
```

## ВИСНОВКИ

1. **Пасивне обладнання** формує фізичну основу PON-мережі та визначає її довговічність:
   - Оптичні сплітери 1:32 є оптимальним вибором для багатоквартирних будинків;
   - Використання волокон G.657.A1 для внутрішньобудинкової прокладки обов'язкове;
   - Конектори SC/APC забезпечують необхідний рівень ORL (≥65 дБ);
   - Якісна пасивна інфраструктура служить ≥25 років без заміни.

2. **Активне обладнання** визначає функціональність та якість послуг:
   - OLT Huawei MA5680T та ZTE C300 — провідні рішення для мереж середнього та великого масштабу;
   - Класифікація ONT за типами SFU/HGU/MDU дозволяє оптимально підібрати обладнання під конкретні потреби:
     - **SFU** — базова квартира (Інтернет + ТБ + телефонія);
     - **HGU** — розширений функціонал (Wi-Fi 6, розумний дім);
     - **MDU** — агрегація для FTTB (під'їзд/підвал).

3. **Виробники Huawei та ZTE** домінують на ринку PON-обладнання в Україні:
   - Huawei — вища ціна, але доведена надійність та широка підтримка;
   - ZTE — оптимальне співвідношення ціна/якість, сумісність з Huawei ONT.

4. **Економічна ефективність** FTTB/FTTH для багатоквартирних будинків:
   - Вартість на абонента: $200–300;
   - Термін окупності: 2–3 роки;
   - Можливість міграції на XGS-PON без заміни пасивної інфраструктури.

5. **Практичні рекомендації:**
   - Для нових ЖК обирати архітектуру FTTH з прямим підключенням кожної квартири;
   - Для існуючих будинків — FTTB з MDU у підвалі;
   - Застосовувати каскадну схему сплітерів (1:4 + 1:8) для гнучкості розгортання;
   - Забезпечити повне маркування та документацію для спрощення експлуатації.
